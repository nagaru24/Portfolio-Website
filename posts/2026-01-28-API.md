## APIキーの作成/入手
1. <a href="https://cloud.google.com/cloud-console?hl=en" target="_blank" rel="noopener noreferrer">Google Cloud Console</a>に任意のGoogleアカウントでログイン。
2. 新規プロジェクトを作成。
3. API & Services → LibraryでGoogle Sheets APIを検索。  
<img width="800" src="/static/blog/2026-01-28/GS API.png">  

4. 有効にする。
5. API & Services → Credentialsに移動し、Create CredentialsからService Accountを選択。
6. 名前をつけたら、IDは自動生成のものを使い、次に進む。
7. OptionalはノータッチでDone。
8. 作成したサービスアカウントを選択し、Keysタブを選択。  
このサービスアカウントのEmailをコピーしておくと吉。後で使う。
9. Add Key → Create new key → JSON → Create。  
このJsonキーはコミットしてはいけないので、Secretフォルダで管理し、.gitignoreにも追加しておく。  
<br><br>

## Google Sheets
1. 参照するデータがあるGoogle Sheetsを開いて、共有を選択。
2. コピーしたサービスアカウントのEmailを追加。  
僕のケースでは読み取りだけなので、Viewer。書き込みもするならEditor権限も付与。  
<br><br>

## ローカル環境での導入
1. APIキーを使用したいプロジェクトフォルダをコードエディターで開く。
2. .envなどを用いて、jsonキーへのパスの確保/明確化。  
PAレポ内では、WSGIファイルを参照することになるのを頭に入れておく。  
`GOOGLE_APPLICATION_CREDENTIALS=C:\your_path_to_the_key`  
3. パス管理用のAPIキー参照例(Python)。  
`os.getenv("GOOGLE_APPLICATION_CREDENTIALS")`  
4. Pythonでのコード例。

```python
from googleapiclient.discovery import build
from google.oauth2 import service_account

SCOPES = ["https://www.googleapis.com/auth/spreadsheets.readonly"]
SHEET_ID = "a1b2c3d4e5f6g7h8i9j10k11l12m13n14"
# Sheet IDは、https://docs.google.com/spreadsheets/d/ここ！/---
```
<br>

もし、APIキーをGitHubにpushしてしまうと、そのキーは使えなくなるので注意！(経験済み)  
同じ手順で簡単に新しいキーは作れます。
